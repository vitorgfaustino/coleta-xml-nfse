# Código de conduta

Adaptado do [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Compromisso

Queremos uma comunidade aberta, respeitosa e útil para pessoas de diferentes experiências, identidades e níveis técnicos.

## Comportamentos esperados

- Trate as pessoas com respeito.
- Critique ideias e código, não pessoas.
- Explique o contexto e o impacto de uma mudança.
- Aceite correções com boa-fé.
- Proteja dados fiscais e credenciais de terceiros.

## Comportamentos inaceitáveis

- Assédio, discriminação, ameaça ou intimidação.
- Comentários sexistas, racistas, homofóbicos, capacitistas ou equivalentes.
- Publicação de dados privados, como PFX, senhas, CNPJs, CPFs, chaves de acesso ou XMLs reais.
- Ataques pessoais, provocação repetida ou interrupção deliberada de discussões.
- Uso do espaço do projeto para spam ou promoção sem relação com o trabalho.

## Escopo

Este código vale em issues, pull requests, discussões, revisões de código e outros espaços do projeto. Também vale quando alguém representa o projeto em outro canal.

## Aplicação

Os mantenedores podem remover, editar ou rejeitar contribuições que violem este código. Podem também advertir, suspender ou bloquear participantes em casos graves ou repetidos.

Para relatar um problema de conduta, use o recurso de contato privado do repositório oficial. Não abra uma issue pública com detalhes pessoais. Relatos serão tratados com discrição e boa-fé.
