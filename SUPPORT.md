# Suporte

## Onde perguntar

- **Bug reproduzível:** abra uma issue com o template de bug.
- **Pedido de recurso:** abra uma issue com o template de recurso.
- **Vulnerabilidade:** use o recurso de Security advisories do repositório. Veja [SECURITY.md](SECURITY.md).
- **Dúvida de uso:** consulte o [README](README.md) e a seção de solução de problemas.

## O que incluir

- Versão do app (`python nfse_app.py --version` ou rodapé da tela).
- Sistema operacional e versão.
- Versão do Python.
- Passos para reproduzir.
- O que você esperava e o que aconteceu.
- Logs com CNPJs, CPFs, nomes e valores removidos.

## O que não incluir

- PFX ou `.p12`.
- Senha do certificado.
- CNPJ, CPF, nome de cliente ou chave de acesso real.
- XML real.
- Captura de tela com dados fiscais.

Use dados sintéticos. Se precisar mostrar um XML, recorte o menor trecho possível e substitua os identificadores.

## Prazo

O suporte é feito por mantenedores em regime de melhor esforço. Não há SLA, plantão ou garantia de resposta.
