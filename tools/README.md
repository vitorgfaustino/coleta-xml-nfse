# Ferramentas opcionais

Esta pasta não é necessária para o primeiro uso. Use `iniciar.bat` ou
`iniciar.command` na raiz.

- `instalar.bat` / `instalar.command`: criam o `.venv` e instalam dependências
  sem abrir o aplicativo. Útil para preparar a máquina, reparar dependências ou
  deixar tudo pronto antes de um agendamento.
- `../build.py` e `../scripts/package.py`: ferramentas locais opcionais de
  empacotamento. Não fazem parte da distribuição oficial e não geram binários
  assinados.
- `../agendar.bat`/`../agendar.ps1`: agendamento no Windows.
